      ASCII mirror - one tag, a unique URL per scan
      
The chip substitutes its UID and/or read counter into the
        data it returns, so identical tags resolve to different URLs. Write a
        URL containing a placeholder of exactly the right width, then point the
        mirror at it.

      
      
      

        

          
          
        

        

          
          
        

      

      

        
        
      

    


    

      NFC read counter
      
A 3-byte counter that increments on the first read after
        each power-on. Mirror it into a URL to get a scan count with no
        server-side state.

      

        
        
      

    


    

      Password protection
      

        This reader cannot send PWD_AUTH. A password can be
        written but never used, which would make the tag permanently
        unwritable here. Tick the override only if you understand that.

Plain URI records are written by default - the only layout that works
     on both iOS and Android. Soft locking sets the capability container
     read-only: phones refuse to write, this reader still can. On genuine NXP
     silicon that flag is one-time programmable and cannot be
     cleared; clone chips often allow Unlock to reverse it. Either way
     the result is verified by reading the byte back.
